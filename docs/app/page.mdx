# SpaceShield Documentation

Welcome to the official documentation for **SpaceShield**, an autonomous satellite outage insurance and compensation protocol designed for the **Spacecoin** ecosystem on Creditcoin / Attestcoin.

> **SpaceShield** answers one question automatically: when a Spacecoin satellite goes down, who gets compensated, how much, and who decides that without a human in the loop?

---

## Key Highlights

- 🛰️ **Autonomous Outage Detection**: Dual-sourced monitoring combining Spacecoin status feeds with real-time NORAD TLE orbital tracking via CelesTrak.
- 🔒 **M-of-N Oracle Attestation**: Multi-oracle consensus requiring independent verification before any payout is triggered.
- ⚡ **Native Query Verification**: Built on Creditcoin/Attestcoin `INativeQueryVerifier` and the Block Prover precompile (`0x0FD2`).
- 💎 **Pull-Based Pro-Rata Settlement**: Subscriber compensation derived from operator bonds, calculated transparently on-chain relative to subscription duration.
